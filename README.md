# Data Analysis of Used Cars on eBay

## Project overview
This project explores used-car listing data to understand how prices and listing counts vary by vehicle type, registration year, fuel type, gearbox, and brand.

## Project contents
- `vechile (2).ipynb` — Jupyter Notebook containing the analysis.
- Original chart image files — saved outputs generated by the notebook.

## Tools and libraries
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Seaborn
- Plotly Express

Install the main dependencies:

```bash
python -m pip install pandas matplotlib seaborn plotly jupyter
```

Start Jupyter Notebook from the project directory:

```bash
jupyter notebook
```

Open `vechile (2).ipynb` and run the cells after checking that the dataset path is correct.

## Analysis performed
The notebook explores:
1. Number of cars by registration year.
2. Number of vehicles by vehicle type.
3. Distribution of vehicle registration years.
4. Average price by vehicle type and gearbox.
5. Average price by fuel type and gearbox.
6. Average price by brand and vehicle type.

## Data preparation
The notebook loads data using Latin-1 encoding and removes rows with missing values using `df.dropna(inplace=True)`. This removes any row containing a missing value in any column, which may discard more records than necessary. Consider handling missing values only in columns used for each analysis.

## Important notes
- The charts describe patterns in the available dataset; they do not establish cause and effect.
- Check implausible prices, registration years, and engine-power values before drawing conclusions.
- The notebook's manually assigned vehicle-category labels should be checked against the grouped data order.
- Unless the dataset contains confirmed sales outcomes, describe counts as listings or records rather than completed sales.
